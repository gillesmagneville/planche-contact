# Contributing to Planche-Contact

🇫🇷 [Version française](CONTRIBUTING.fr.md)

Thank you for your interest in contributing to **Planche-Contact**.

Contributions of all kinds are welcome, including bug reports, feature requests, documentation improvements, translations and code contributions.

By taking part in this project, you agree to follow its [Code of Conduct](CODE_OF_CONDUCT.md).

## Reporting Bugs

If you discover a bug, please open an Issue on GitHub and provide as much information as possible:

- Operating system and version
- Planche-Contact version
- Steps to reproduce the problem
- Expected behaviour
- Actual behaviour
- Error messages or screenshots (if applicable)

## Suggesting Enhancements

Suggestions for new features or usability improvements are welcome.

Before opening a new Issue, please check whether the feature has already been requested.

When possible, explain:

- the problem you are trying to solve;
- why the proposed solution would be useful;
- possible alternatives.

## Contributing Code

If you would like to contribute code:

1. Fork the repository.
2. Create a feature branch.
3. Keep your changes focused on a single feature or bug fix.
4. Test your modifications before submitting them.
5. Submit a Pull Request with a clear description of your changes.

## Coding Guidelines

Please try to keep the code:

- readable;
- well documented;
- consistent with the existing coding style;
- compatible with supported Python versions.

## Documentation

Documentation improvements are always appreciated.

This includes:

- README improvements;
- translations;
- installation instructions;
- examples;
- screenshots.

The project documentation (`README.md`, `CONTRIBUTING.md`, `CODE_OF_CONDUCT.md`, `CHANGELOG.md`, `PROJECT_CONTEXT.md` and `windows/README.md`) is bilingual: the English version is the default file (`X.md`) and the French version sits next to it (`X.fr.md`). When you change one of them, please update the other too, or say so in your Pull Request so that the maintainer can update it.

## Translations

The interface is available in English, French, German and Spanish. The strings live in `portfolio/locales/` (one file per language: `en.py`, `fr.py`, `de.py`, `es.py`); `en.py` must always stay complete, because English is the fallback language.

Corrections to existing translations and translations into other languages are welcome and may be integrated after review and testing.

The user manual (`docs/planche-contact-manual*.html`) exists in the same four languages.

## Questions

If you have questions, feel free to open a GitHub Issue.
