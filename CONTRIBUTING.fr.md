# Contribuer à Planche-Contact

🇬🇧 [English version](CONTRIBUTING.md)

Merci de l'intérêt que vous portez à **Planche-Contact**.

Les contributions de toute nature sont les bienvenues : signalements de bugs, demandes de fonctionnalités, améliorations de la documentation, traductions et contributions de code.

## Signaler un bug

Si vous découvrez un bug, merci d'ouvrir une Issue sur GitHub en fournissant le plus d'informations possible :

- Système d'exploitation et sa version
- Version de Planche-Contact
- Étapes pour reproduire le problème
- Comportement attendu
- Comportement constaté
- Messages d'erreur ou captures d'écran (le cas échéant)

## Suggérer des améliorations

Les suggestions de nouvelles fonctionnalités ou d'améliorations de l'ergonomie sont les bienvenues.

Avant d'ouvrir une nouvelle Issue, merci de vérifier que la fonctionnalité n'a pas déjà été demandée.

Dans la mesure du possible, expliquez :

- le problème que vous essayez de résoudre ;
- en quoi la solution proposée serait utile ;
- les alternatives envisageables.

## Contribuer du code

Si vous souhaitez contribuer du code :

1. Faites un fork du dépôt.
2. Créez une branche dédiée à la fonctionnalité.
3. Gardez vos modifications centrées sur une seule fonctionnalité ou un seul correctif.
4. Testez vos modifications avant de les soumettre.
5. Soumettez une Pull Request avec une description claire de vos changements.

## Conventions de code

Merci de veiller à ce que le code reste :

- lisible ;
- bien documenté ;
- cohérent avec le style de code existant ;
- compatible avec les versions de Python prises en charge.

## Documentation

Les améliorations de la documentation sont toujours appréciées.

Cela comprend :

- les améliorations du README ;
- les traductions ;
- les instructions d'installation ;
- les exemples ;
- les captures d'écran.

La documentation du projet (`README.md`, `CONTRIBUTING.md`, `CHANGELOG.md`, `PROJECT_CONTEXT.md` et `windows/README.md`) est bilingue : la version anglaise est le fichier par défaut (`X.md`) et la version française se trouve à côté (`X.fr.md`). Lorsque vous modifiez l'une d'elles, merci de mettre l'autre à jour également, ou de l'indiquer dans votre Pull Request afin que le mainteneur puisse la mettre à jour.

## Traductions

L'interface est disponible en anglais, en français, en allemand et en espagnol. Les chaînes se trouvent dans `portfolio/locales/` (un fichier par langue : `en.py`, `fr.py`, `de.py`, `es.py`) ; `en.py` doit toujours rester complet, car l'anglais est la langue de repli.

Les corrections des traductions existantes et les traductions dans d'autres langues sont les bienvenues et pourront être intégrées après relecture et tests.

Le manuel d'utilisation (`docs/planche-contact-manual*.html`) existe dans les quatre mêmes langues.

## Questions

Si vous avez des questions, n'hésitez pas à ouvrir une Issue GitHub.
