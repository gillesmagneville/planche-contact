Planche-Contact — Manuel complet

1. Présentation

Planche-Contact est un outil léger et rapide permettant de générer des planches contact photographiques de haute qualité (300 dpi), à partir d'un dossier de photos, sans base de données ni logiciel lourd.

Il existe sous deux formes :

  • Interface graphique GTK4 (planche-contact-gtk.py / planche-contact-gtk)
  • Ligne de commande (portfolio.py)

À partir d'un même dossier de photos, l'outil peut produire simultanément :

  • des planches contact au format JPEG (une ou plusieurs pages) ;
  • un PDF assemblant toutes les planches ;
  • une galerie HTML paginée, autonome, avec vignettes cliquables ;
  • un index CSV listant chaque photo avec son numéro.

2. Formats de photos pris en charge

TypeExtensions
Formats standards.jpg, .jpeg, .png, .tif, .tiff, .bmp, .webp, .heic, .heif
Formats RAW.cr2, .cr3 (Canon), .nef (Nikon), .dng, .arw (Sony)
Le support des fichiers RAW s'appuie sur la bibliothèque rawpy, installée automatiquement dans le paquet .deb (aucune installation manuelle nécessaire). Pour accélérer le traitement, Planche-Contact utilise en priorité l'aperçu JPEG déjà embarqué dans le fichier RAW par l'appareil photo ; un dématriçage complet (plus lent) n'est déclenché que si cet aperçu est absent ou trop petit pour l'usage demandé (vignette, planche, image "pleine taille" de la galerie).

L'orientation des photos (portrait ou paysage) est toujours respectée telle qu'indiquée par l'appareil photo, sur les trois sorties (planches, PDF, galerie HTML) — aucune manipulation manuelle n'est nécessaire, y compris pour des photos prises l'appareil tenu à la verticale.

3. Interface graphique (GTK)

3.1 Fenêtre principale

La fenêtre s'ouvre maximisée par défaut (tout en restant redimensionnable normalement) et propose trois onglets : Génération, Aide et À propos. L'onglet Aide ouvre ce manuel dans le navigateur par défaut.

3.2 Onglet « Génération »

Champ / OptionDescription

Nom de l'auteurNom affiché sous le titre (en gras, plus petit).
Dossier d'entréeDossier contenant les photographies à traiter (obligatoire). Affiche automatiquement un aperçu des photos du dossier (voir §3.3).
Dossier de sortieDossier où seront créés les résultats. Par défaut : Portfolio/ dans le dossier source. Créé automatiquement s'il n'existe pas encore.
Recherche récursiveSi coché, analyse aussi tous les sous-dossiers.
Images par plancheNombre de vignettes par page (8 à 48, par pas de 4). Sur la même ligne que les trois champs suivants.
Format de la plancheFormat papier : A5, A4, A3, A2 ou Letter.

  • Diagonale horaire : texte incliné dans le sens des aiguilles d'une montre

Si aucun des trois champs Titre / Auteur / Filigrane n'est renseigné, l'en-tête des planches affiche par défaut le nom du dossier d'entrée (sans son chemin complet), pour éviter une planche totalement anonyme.

3.3 Aperçu du dossier d'entrée

Dès qu'un dossier d'entrée valide est renseigné (au démarrage si un dossier était déjà mémorisé, ou après saisie/sélection), une bande d'aperçu affiche automatiquement les vignettes des photos qu'il contient, par pages de 10, avec une pagination numérotée (← Précédent 1 … 4 5 6 … 19 Suivant →). Le scan et la génération des vignettes se font en arrière-plan : l'interface ne se fige pas, même sur un dossier contenant des centaines de photos.

3.4 Sélecteur de dossier personnalisé

Le bouton « Choisir... » (dossier d'entrée ou de sortie) ouvre un navigateur de dossiers entièrement construit par l'application, plutôt que la boîte de dialogue native du système :

  • Uniquement des dossiers sont affichés (aucun fichier), pour une navigation épurée.
  • Un panneau d'aperçu en bas affiche jusqu'à 20 vignettes (2 lignes de 10) des photos du dossier survolé, avec sa propre pagination.
  • Un fil d'Ariane cliquable en haut permet de remonter rapidement dans l'arborescence.
  • Une barre latérale propose un raccourci vers le dossier personnel, ainsi que les signets déjà enregistrés dans le système (les mêmes que dans le gestionnaire de fichiers), s'il y en a.
  • Double-cliquer sur un dossier y entre ; le bouton « Sélectionner ce dossier » valide le dossier actuellement affiché.

3.5 Bouton « Afficher les résultats »

Après une génération réussie, ce bouton (à liste déroulante) permet d'ouvrir directement les résultats avec les applications par défaut du système, sans agrandir la fenêtre principale :

OptionAction
Planches contactOuvre le dossier planches/ dans le gestionnaire de fichiers par défaut.
Portfolio PDFOuvre le PDF avec le lecteur par défaut.
Galerie HTMLOuvre la galerie dans le navigateur par défaut.
Index CSVOuvre le fichier CSV avec l'application par défaut (tableur, généralement).

Chaque option n'est activée que si l'élément correspondant a bien été généré (selon les cases cochées lors de la génération). Si aucune application par défaut n'est configurée sur le système pour un type de fichier donné, une fenêtre d'avertissement s'affiche, avec une suggestion d'application à installer.

3.6 Onglet « À propos »

Affiche le numéro de version, la date de build, une courte description, l'auteur, la licence (GNU GPL v3) et un lien cliquable vers le dépôt GitHub du projet.

4.2 Exemples complets

# Génération simple
python3 portfolio.py -i /Photos/2025 -o ./Sortie --pdf --html

# Galerie HTML avec 24 images par page au lieu de 48 par défaut
python3 portfolio.py -i /Photos/2025 -o ./Sortie --html --html-per-page 24

# Version professionnelle avec filigrane diagonal et opacité personnalisée
python3 portfolio.py \
  -i /Photos/Islande \
  -n 16 \
  --format A3 \
  --title "Islande 2025" \
  --author "Abel GEZ" \
  --watermark "Abel GEZ" \
  --watermark-orientation "Diagonale horaire" \
  --watermark-opacity 55 \
  --pdf --html --csv

5. Filigrane

Le filigrane utilise un rendu unique et identique quel que soit le support de sortie : planches contact, PDF (qui réutilise directement les images de planches) et galerie HTML (vignettes de la grille et images « pleine taille »). Le texte est répété en mosaïque sur toute l'image, avec l'orientation et l'opacité choisies — aucune différence de rendu entre les trois sorties.

7. Recommandations

  • Pour un rendu homogène, conservez le même nombre d'images par planche sur tout le projet.
  • Le filigrane en diagonale est généralement plus élégant et moins gênant visuellement.
  • La galerie HTML est autonome : vous pouvez copier tout le dossier gallery/ ailleurs (clé USB, serveur web...) sans rien casser.
  • Sur les dossiers volumineux (plusieurs centaines de photos), le traitement exploite automatiquement tous les cœurs disponibles de la machine : plus la machine dispose de cœurs, plus la génération est rapide.
