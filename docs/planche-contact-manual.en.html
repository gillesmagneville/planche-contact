Planche-Contact — Full Manual

1. Overview

Planche-Contact is a lightweight, fast tool for generating high-quality (300 dpi) photographic contact sheets from a folder of photos, with no database and no heavy software.

It comes in two forms:

  • GTK4 graphical interface (planche-contact-gtk.py / planche-contact-gtk)
  • Command line (portfolio.py)

From the same folder of photos, the tool can produce simultaneously:

  • contact sheets in JPEG format (one or several pages);
  • a PDF assembling all the sheets (captions, title and page numbers can be selected, copied and searched in any PDF viewer);
  • a paginated, self-contained HTML gallery with clickable thumbnails opening each photo in a full-screen viewer: filename and page number shown, navigation between the photos on the page (keyboard or ‹ › arrows), direct jump to another page, 50% to 200% zoom, download of the displayed photo (or of the full-size original, with the "Full-size originals in the gallery" option), technical information (original resolution, size, capture date) and fullscreen toggle;
  • a CSV index listing every photo with its number.
On Windows, the first time you run the installer, Windows will very likely show a blue "Windows protected your PC" screen (SmartScreen). This is expected for a small, unsigned piece of software — not a sign of malware. Click More info, then Run anyway to proceed.

2. Supported photo formats

TypeExtensions
Standard formats.jpg, .jpeg, .png, .tif, .tiff, .bmp, .webp, .heic, .heif
RAW formats.cr2, .cr3 (Canon), .nef (Nikon), .dng, .arw (Sony)
RAW support relies on the rawpy library, installed automatically in the .deb package (no manual installation needed). To speed up processing, Planche-Contact preferentially uses the JPEG preview already embedded in the RAW file by the camera; a full (slower) demosaic is only triggered if that preview is missing or too small for the intended use (thumbnail, sheet, "full-size" gallery image).

Photo orientation (portrait or landscape) is always respected exactly as indicated by the camera, across all three outputs (sheets, PDF, HTML gallery) — no manual adjustment is needed, including for photos taken with the camera held vertically.

3. Graphical interface (GTK)

3.1 Main window

The window opens at the size of its content, reduced if needed to fit the screen (it remains normally resizable). On a small screen, the form of the Generation tab scrolls (scrollbar), while the bottom of the window — the "Start generation", "Advanced settings…", "Reset", "View results" and "Quit" buttons, the progress bar and the log — always stays visible. It offers three tabs: Generation, Help and About. The Help tab opens this manual in the default browser.

3.3 Layout, captions and theme (advanced settings)

The "Advanced settings…" button in the main window opens a separate window that lets you fine-tune the layout, captions and graphical theme colors of the contact sheets (the theme itself is chosen in the main window, see §3.2) — as long as you leave it alone, the sheets show the file name under each photo (the default; it can be switched off here). This window closes with the "Close" button or the Escape key; your settings are kept between two openings. On a small screen its content scrolls (scrollbar) and the "Close" button always stays visible.

Layout

Applies to the sheets and the PDF; the HTML gallery keeps the photos' proportions. A photo smaller than its cell is never enlarged.

Also applies to the header of the HTML gallery.

Per-photo captions

A caption can be shown below (or above) each thumbnail, built from the photo's EXIF metadata:

  • Filename, date taken, camera (make/model), lens, focal length, 35 mm-equivalent focal length, aperture, shutter speed, ISO sensitivity, image dimensions, GPS position.
  • Position, reserved area (mm), number of lines, font size and alignment are all configurable.
  • Text that is too wide for the thumbnail wraps automatically, between fields: no information is cut off. Extra lines are added as needed, and the thumbnails shrink slightly to make room for them.
  • A metadata field missing from a given photo (for example no GPS data) is simply left out of its caption, never causing an error.
GPS position, if enabled, is shown in plain text on the generated sheet — only turn it on if you actually want to share that information (a warning is shown when hovering over the corresponding checkbox).

Graphical theme

Four modes, chosen from the "Theme" list in the main window (see §3.2) and applied identically to the JPEG contact sheets, the PDF and the HTML gallery: Light (default), Dark, Neutral, and System (for the HTML gallery, it follows each visitor's own browser, with a small discreet button letting them switch between light and dark themselves; a JPEG sheet or a PDF being a fixed image that cannot follow the system theme, they stay light in this mode). This advanced block only contains the background, text, accent and border colors, which can be customized individually (hex format #rrggbb) to override those of the chosen theme. In the HTML gallery, the small ◐ button (in the page footer) switches the page from the chosen theme to its light/dark opposite; a second click returns exactly to the chosen theme. The visitor's choice is remembered in their browser, but only for the current gallery: a regenerated gallery always starts again from the theme chosen in the main window.

Save / Load a profile

All of these settings (layout, captions and theme) can be saved to a reusable JSON file ("Save profile..." button), then loaded again later ("Load profile..." button) — handy for applying the same settings to several projects, or for sharing them. This same file can be passed to the command line via --profile (see §4.1).

3.4 Contact sheet preview

The "Preview sheet..." button, in the advanced settings window, shows, in a dedicated window, the contact sheet exactly as it will actually be produced — layout, captions, theme and watermark included — using the first photos in the input folder (the same number the real generation would place on that first page). Handy for checking the effect of a setting before running a full generation, especially on a folder containing many photos.

3.5 Input folder preview

As soon as a valid input folder is set (at startup if a folder was already remembered, or after typing/choosing one), a preview strip automatically shows thumbnails of the photos it contains, in pages of 10, with numbered pagination (← Previous 1 … 4 5 6 … 19 Next →). Scanning and generating thumbnails happens in the background: the interface never freezes, even for a folder containing hundreds of photos.

3.6 Custom folder picker

The "Choose..." button (input or output folder) opens a folder browser entirely built by the application, rather than the system's native dialog:

  • Only folders are shown (no files), for a clean navigation experience.
  • A preview panel at the bottom shows up to 20 thumbnails (2 rows of 10) of the photos in the hovered folder, with its own pagination.
  • A clickable breadcrumb trail at the top lets you quickly move up the folder tree.
  • A sidebar offers a shortcut to your home folder, as well as any bookmarks already saved on the system (the same ones as in your file manager), if any.
  • Double-clicking a folder enters it; the "Select this folder" button confirms the currently displayed folder.

3.7 "View results" button

After a successful generation, this dropdown button lets you open the results directly with the system's default applications, without enlarging the main window:

OptionAction
Contact sheetsOpens the planches/ folder in the default file manager.
Portfolio PDFOpens the PDF with the default viewer.
HTML GalleryOpens the gallery in the default browser.

Each option is only enabled if the corresponding item was actually generated (based on the checkboxes selected during generation). If no default application is configured on the system for a given file type, a warning window appears, suggesting an application to install.

3.8 "About" tab

Shows the version number, build date, a short description, the author, the license (GNU GPL v3) and a clickable link to the project's GitHub repository. Also includes the language selector — see the note below.

Changing the language takes effect after restarting the application. The chosen language is also used for the command line and for any HTML gallery generated afterwards — see §4 and §5.

4.2 Full examples

# Simple generation
python3 portfolio.py -i /Photos/2025 -o ./Output --pdf --html

# HTML gallery with 24 images per page instead of the default 48
python3 portfolio.py -i /Photos/2025 -o ./Output --html --html-per-page 24

# Professional version with diagonal watermark, custom opacity, in English
python3 portfolio.py \
  -i /Photos/Iceland \
  -n 16 \
  --format A3 \
  --title "Iceland 2025" \
  --author "Abel GEZ" \
  --watermark "Abel GEZ" \
  --watermark-orientation "Diagonale horaire" \
  --watermark-opacity 55 \
  --language en \
  --pdf --html --csv

5. Watermark

The watermark uses a single, identical rendering regardless of the output: contact sheets, PDF (which directly reuses the sheet images) and HTML gallery (grid thumbnails and "full-size" images). The text is repeated in a mosaic pattern across the whole image, with the chosen orientation and opacity — no difference in rendering between the three outputs.

7. Recommendations

  • For a consistent look, keep the same number of images per sheet throughout a project.
  • A diagonal watermark is usually more elegant and visually less intrusive.
  • The HTML gallery is self-contained: you can copy the whole gallery/ folder elsewhere (USB drive, web server...) without breaking anything.
  • For the viewer's download button to trigger the browser's usual save dialog (rather than opening the image), view the gallery through a web server rather than double-clicking index.html directly (see the note below).
  • If the gallery appears dark although the Light or Neutral theme is chosen, the browser is forcibly darkening it: the "Auto Dark Mode for Web Contents" option of Chrome/Edge (chrome://flags/#enable-force-dark) or an extension that darkens pages. The gallery declares its theme to the browser, which prevents this darkening when the browser's preference is dark, but not when it is forced unconditionally: turn the option off, or add the gallery to the extension's exceptions. To check, open index.html in another browser or in a private window.
  • For large folders (several hundred photos), processing automatically uses all available cores on the machine: the more cores, the faster the generation.
When the gallery is opened directly by double-clicking index.html (without a web server), browsers block, for security reasons, reading neighbouring files, and therefore the usual scripted download. With the "Full-size originals in the gallery" option, each original comes with a small .js file (originals/IMG_1.jpg.js) that the viewer loads on demand: the ⇩ button then downloads the JPEG under its name, with the browser's usual dialog, even when double-clicked and whatever the browser. Without that option (reduced copy), or if a companion file is missing, the button uses a plain download link: depending on the browser, it triggers the save or opens the image in a new tab (which is what Chrome and Chromium-based browsers do), and a message appears in the viewer explaining this. If the image opened in a new tab, right-clicking it and choosing "Save image as" still works normally in that case. To get one-click downloads back, simply view the gallery through a web server instead of locally — a simple command such as python3 -m http.server run inside the gallery folder is enough, with nothing else to install.
